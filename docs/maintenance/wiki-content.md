# Wiki publishing and graph maintenance

## Authoring and routes

The Wiki home is `/wiki/` (English: `/en/wiki/`) and uses the house emoji.
Its Markdown introduction describes a personal knowledge base. The global graph
is appended after the final `document-graph` heading by the original-theme content
wrapper. Other wiki documents and blog detail pages receive a local graph and
connection lists automatically. Blog listing previews never mount graphs.

Authored topic documents live in `content/{ko,en}/wiki/d/`. Their old
`/wiki/knowledge/` addresses are static compatibility pages generated by the
official redirects plugin. `/wiki/graph/` is a compatibility document only, not
a content node; it forwards query/hash information to Wiki Home. Old node IDs
using `knowledge` are normalized when the home graph reads selection parameters.
Canonical document HTML uses directory-index output so trailing slashes work on
static hosts without relying on a 404-page recovery script.

Every wiki title and category label starts with one emoji. Translations keep
the source emoji; brain emojis are not used. Source validation also checks local-only
notes before publication filtering. English category labels are generated from
the localized category sources into Docusaurus's standard `current.json` translation
file: localized category files by themselves do not translate the default sidebar.

## Publication modes and dates

Root `.docignore` defines public exclusions. `npm run dev` includes excluded sources
from `_guide/` and `_design/` under the local `/wiki/guide/` and `/wiki/design/`
aliases. A localized, generated warning precedes the document body and any English
fallback notice. Authored source Markdown is never modified to insert warnings.
Rules cover wiki/blog content under `content/` and accept root-relative globs and
directory rules, not gitignore negation. They do not filter arbitrary site pages.

Public builds omit excluded pages and their assets before metadata, graph, search,
tags and sitemap generation. Build preparation is guarded against mixing a previous
development staging tree into a public build. This is not authentication: files in
a public repository remain readable, and LAN development is not a private service.

Last-update footers use official Docusaurus components. Preparation injects the
authored file's latest Git commit date into generated front matter, preserving
explicit `last_update.date` values. English fallback pages inherit the Korean
source date. Dates are formatted in UTC by the upstream component; builds and
uncommitted edits do not fabricate new dates. Both CI checkouts fetch full history.

## Graph behavior

The shared canonical content network remains the single source for graph, tags
and backlinks. A local neighborhood includes direct outgoing/incoming documents
and the current document's own tags, not every sibling sharing a tag. Related
documents remain available as text links. A single isolated node is valid.

The renderer mounts automatically near the viewport, pauses simulation/rendering
offscreen or in a hidden tab, and cleans up on navigation. Dragging is distinct
from selecting a node. The native node selector and link provide keyboard access.
Scoped theme colors and reduced-motion preferences apply to both graph variants.

D3 and Pixi still load from jsDelivr, as in the existing renderer. A blocked CDN
does not prevent reading documents or following their text links. The renderer
has a loading timeout and retry; failed script promises are cleared for recovery.
This work does not replace that existing external asset dependency.

```sh
npm run test:content
npm run test:ui
npm run typecheck
SITE_URL=https://jyje.github.io SITE_BASE_URL=/profile-2/ npm run build
npm run test:publication
npm run test:wiki
node scripts/verify-built-site.mjs

# Against the running all-locale development server:
SITE_CONTENT_MODE=development VERIFY_ORIGIN=http://127.0.0.1:3000 VERIFY_BASE_PATH=/ npm run test:wiki
```

The wiki browser check covers both locales, legacy query/hash forwarding, inline
and global graphs, actual node dragging, native selection and keyboard focus,
390/864/1222px widths, light/dark themes, pause/resume, failed CDN loading/retry,
touch controls, reduced motion and development-only notices. Screenshots are
written to the ignored `.playwright-mcp/wiki-completion/` directory.

Delivery is local-only. No remote PR, push, merge or deployment is part of this
completion. Final verification evidence is recorded below before temporary plans
and the root execution checklist are removed in a separate commit.
