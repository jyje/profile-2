# 🛠️ 이력서 접근 요청과 공개 경계

## 현재 문서 제공 방식

[이력서 접근 요청](/about/resume/)에서 LinkedIn 수동 문의를 안내합니다. 기존 경력기술서와 전체 CV 주소는 제공 방식 변경 안내만 표시합니다. 로그인, 요청 저장, 승인 기능은 아직 없습니다.

공개 프로젝트는 [포트폴리오](/about/portfolio/)와 기존 블로그 글에서 소개합니다.

## 원본과 편집 {#data-contract}

상세 경력 원본, 직무별 선택, 이력서·CV 출력은 별도 비공개 작업 공간에서 관리합니다. 이 공개 사이트는 그 원본에 의존하지 않습니다. 공개 MDX에는 승인된 공개 설명만 작성합니다. 초안 표시나 로컬 호스트 여부는 비공개 수단이 아닙니다.

## 검증 {#validation-resume-lint}

공개 빌드에서는 경력 본문, 생성 JSON, CV 태그 항목, PDF 산출물을 제공하지 않아야 합니다. 콘텐츠 테스트와 빌드 후 게시 검증으로 이 경계를 검사합니다. 브라우저 검증은 두 언어의 탐색·기존 주소·모바일 화면과 LinkedIn 링크를 확인합니다.

비공개 문서의 A4 페이지 수와 가독성 검증은 비공개 작업 공간에서 수행합니다. 과거 공개본과 Git 이력은 이번 전환으로 삭제되지 않습니다.
